# Homepage background

Source: [ign_unsplash40.png](https://github.com/linuxdotexe/nordic-wallpapers/blob/master/wallpapers/ign_unsplash40.png) from linuxdotexe/nordic-wallpapers.

`background.webp` is a compressed derivative: resized from 5616×3744 to 2560×1707 with Lanczos resampling, then encoded as WebP at quality 85, method 6 using Pillow. The original 11,764,590-byte PNG is not stored here; the WebP is 832,940 bytes (92.9% smaller).

Homepage uses the public raw GitHub URL for this asset, so clients need access to raw.githubusercontent.com. The background appears once this file is merged into master.
